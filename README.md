## Собственный проект

Тема проекта: Коллекция фильмов

Главный класс: Фильм

Почему этот объект нужен программе:
Чтобы программа работала и выводила коллекцию фильмов.

Какие данные хранит объект:

- Название
- Дату создания
- Жанр
- Оценку

Какие значения задаются через конструктор:
Название, Дата создания фильма, его жанр и оценка в 10 бальной шкале.

Какое значение я решила задавать автоматически и почему:
Доступность фильма, потому что это значение для всех фильмов одинаково.
